HP制作

法人/採用用HP制作

医療法人の採用サイト制作を担当しました。多職種が在籍するクリニックの採用サイトとして、求職者が働くイメージを具体的に持てるよう、職種ごとの情報設計やコンテンツ構成から企画しました。
ターゲットとなる求職者層を意識し、安心感と親しみやすさを両立したデザインを設計。Illustratorを用いて全体のビジュアルを制作し、実際に現地で撮影した写真はPhotoshopで色味や明るさを調整し、統一感のある仕上がりにしています。また、スタッフインタビューや1日の業務フローなどのコンテンツを整理し、応募への心理的ハードルを下げる導線設計を行いました。
コーディングはDreamweaverを使用し、レスポンシブ対応を含めた実装を行っています。構成・デザイン・撮影・画像加工・コーディングまで一貫して担当いたしました。

■ 担当範囲

・ バナー・グラフィック素材作成
・ 写真撮影および編集
・ コピーライティングおよびコンテンツ構成
・ Webデザイン・フロントエンドコーディング（Illustrator、Photoshop、Dreamweaver使用）
・ レスポンシブ対応（PC・タブレット・スマホ最適化）

■ 使用ツール / 技術

・ Illustrator
・ Photoshop
・ Dreamweaver
・ HTML / CSS / JavaScript
